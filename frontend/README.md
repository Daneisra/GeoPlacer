# Interface de GeoPlacer

Le tableau de bord utilise React, TypeScript et Vite. Le serveur GeoPlacer
sert l’interface compilée et l’API locale.

Depuis la racine du dépôt, `npm run dev` lance le serveur et l’interface en
mode développement. `npm run build` compile l’application entière et
`npm run lint:frontend` vérifie le code du tableau de bord.

Voir [les commandes](../docs/fr/commandes.md) et
[le guide utilisateur](../docs/fr/guide-utilisateur.md).
